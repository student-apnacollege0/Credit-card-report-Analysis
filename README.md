Credit Card Report Analysis
About the Project

In this project, I analyzed credit card data using Power BI. I created a dashboard to understand customer spending and transaction details.

Tools Used

- Power BI
- Excel
- SQL

What I Analyzed

- Total revenue
- Customer spending
- Credit card transactions
- Weekly and monthly revenue
- Customer behavior

Project Objective

The main goal of this project is to understand customer spending patterns and analyze credit card transactions to get useful insights from the data.

Conclusion

This project helped me learn how to analyze data and create an interactive dashboard using Power BI.
